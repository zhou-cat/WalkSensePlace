Reading this map

A kernel density estimate (quartic kernel) — the same method as ArcGIS Kernel Density. Color maps to crossings per km² on a fixed scale, not a screen-relative blur.

Bandwidth is the one real knob. It's the kernel search radius: widen it and density spreads and flattens, narrow it and peaks sharpen. Tie it to a walking distance you can justify and report it.

Set Max density once (the status line shows the current peak) so areas stay comparable. Stepped classifies the same surface into bands; for true isolines run Contour on the density raster in ArcGIS. Raw crossing density still leans toward busy arterials.

Hover a cell for its count. This is the layer you'd feed an index — one value per fixed-geometry cell.

Only cells containing a crossing are drawn here. For the real index, generate the full tessellation in ArcGIS (Generate Tessellation → Summarize Within) so zero-count cells exist too, then join these counts.

The count ceiling fixes the color scale — keep it constant across any maps you compare.
